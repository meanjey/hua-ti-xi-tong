# 刷题系统（网页版）

交通运输 829 题刷题系统：选择题 501（单选 135 / 多选 366）+ 判断改错题 328，答案逐题核对，判断错题附改句。

- 算法：FSRS 间隔复习（目标保持率默认 93%，可调），四档评分（忘了 / 模糊 / 记得 / 很熟）带间隔预告
- 掌握门槛：稳定性 ≥ 21 天 + 至少 3 次间隔 ≥ 7 天的成功回忆 + 可提取率 ≥ 95%
- 答错自动回炉：当天连对 2 次才出队；错题本、收藏、旗标、答题卡、全量模考、8 种练习模式
- 学习计划可调：每日新题 / 复习上限、组织方式（复习优先 / 新题优先 / 交错）、题目顺序

## 使用

打开 GitHub Pages 网址即可刷题（仓库 Settings → Pages → Source 选 `main` 分支、根目录 `/`）。

整个应用就是一个 `index.html`（约 957 KB），829 题和 11 张配图全部内嵌，没有任何服务端依赖。

## 学习记录说明

本版进度保存在**浏览器本地**（持久化存储 + 双份保存），并提供：

- 设置页「备份与恢复」：一键导出 / 导入进度 JSON（建议每周导出一次）
- 超过 7 天未备份时，今日页顶部会有提醒

注意：清除浏览器网站数据会清掉本地进度。长期学习（如 30 天计划）建议以云端版为主力，本网页版作为随开随用的备用入口。
